# 🎯 Habit Tracker - Gestão de Hábitos e Metas

## 📖 Proposta do Projeto
O **Habit Tracker** é uma aplicação web voltada para o acompanhamento diário de hábitos, tarefas e metas pessoais.
## 🎯 Propósito
O propósito principal da aplicação é **ajudar pessoas a construírem e manterem rotinas saudáveis e produtivas**. Ao invés de interfaces complexas que geram sobrecarga cognitiva, o Habit Tracker aposta no minimalismo e em feedbacks visuais diretos (como o acompanhamento de *streaks* ou sequências de dias) para incentivar a disciplina e o autodesenvolvimento diário.

## Principais Funcionalidades
Atualmente, a interface contempla as seguintes funcionalidades e fluxos:
* **Dashboard de Tarefas (ToDo):** Visualização rápida dos hábitos do dia (ex: Beber água, Academia, Estudar) com checkboxes interativos.
* **Detalhamento em Accordion:** Expansão suave dos cards de hábitos para exibir o resumo diário, horário, categoria e sequência de dias (*streak*) sem necessidade de carregamento extra.
* **Gestão de Categorias:** Organização dos hábitos por áreas da vida (Exercício Físico, Estudos, Hidratação, etc.).
* **Perfil do Usuário (Minha Conta):** Painel com informações do usuário, gestão de conta e um panorama geral das sequências de dias consecutivos (gamificação).
* **Navegação SPA Simulada:** Estrutura de navegação limpa através de menus estáticos com feedback visual de página ativa.
